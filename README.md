# kb-kk-competencies — интеграционный модуль

Каталог и карты компетенций, банк вопросов, назначение тестов, попытки и результаты
для **совместимого полного хоста kb-kk**. Это **не самостоятельное приложение,
не pip-пакет и не отдельный сервис**. Нет собственной авторизации, БД-заглушки,
Docker-стека или независимого запуска. Копия модуля также входит в публичный
`gRasseye3d/kb-kk`; приватность этого репозитория не делает ту копию закрытой.

## Состав

- `kb/app/handlers/{competencies,testing}.py` — серверный модуль.
- `kb/static/js/views/{competencies,testing}.js`, `kb/static/css/competencies.css` — UI.
- `kb/sql/04_testing.sql`, `05_testing_review.sql` — миграции тестирования.
- `03_sessions_v4.sql`, `06_login_rate_limits.sql` — **миграции хоста**, включены
  для полного интеграционного контракта и safety-тестов.
- `docs/schema_conflunce_v4.sql` и notes — **полная схема хоста**, не отдельная
  схема компонента. Исходное ТЗ v4 — требования, не обещание полной реализации.
- `kb/tests/` — выбранные тесты интеграции с хостом, не standalone test suite.
- `component-manifest.json` — SHA256 каждого поставляемого файла компонента,
  документов/тестов и совместимых общих файлов полного хоста.

Быстрая автономная проверка **только целостности** (не запуска приложения):

```sh
python3 tools/verify_manifest.py
```

Установка overlay и проверка **на временной локальной копии полного хоста**:
[INTEGRATION.md](INTEGRATION.md). Сначала проверьте shared-file hashes; эти файлы
намеренно не продублированы в модуле как якобы автономная авторизация.

Не реализованы несколько блоков теста, редактирование опубликованных версий,
уровень 3/собеседования и административное снятие зависших резервов попыток.
Перенос старой схемы 01/02 не поддерживается; они не включены.
