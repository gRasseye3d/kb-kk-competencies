# Ручная публикация владельцем

Создан только локальный репозиторий с одним начальным commit. Remote не добавлен,
GitHub-репозиторий не создавался, push не выполнялся.
Проверьте `git status`, `git ls-files`, секреты и аккаунт `gh auth status`.

Если вы сами готовы опубликовать, из корня **этого** репозитория:

```sh
gh repo create gRasseye3d/kb-kk-competencies --private --source . --remote origin --push
```

Команда — только инструкция, не выполнялась при подготовке. При существующем
репозитории сначала проверьте remote/историю; не используйте force push.
Исходники модуля также присутствуют в публичном полном проекте kb-kk:
приватность этого репозитория не ограничивает доступ к той копии.
