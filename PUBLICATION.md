# Ручная публикация владельцем

Локальный репозиторий компонента: `origin` уже настроен на
`https://github.com/gRasseye3d/kb-kk-competencies.git`. Обновления готовятся
локально: никакой push и развёртывание при подготовке не выполняются.
Проверьте `git status`, `git ls-files`, секреты и аккаунт `gh auth status`.

Если вы сами готовы опубликовать, из корня **этого** репозитория:

```sh
git ls-remote origin refs/heads/main
git push origin main
```

Команды — только инструкция владельцу, push при подготовке не выполнялся.
Убедитесь в приватном статусе репозитория перед push; при расхождении историй
остановитесь, не используйте force push.
Исходники модуля также присутствуют в публичном полном проекте kb-kk:
приватность этого репозитория не ограничивает доступ к той копии.
