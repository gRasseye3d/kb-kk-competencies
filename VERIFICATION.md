# Проверки

Выполнены до локального начального commit:

- Manifest: 17 поставляемых source/docs/test файлов и 41 shared-файл совместимого
  полного хоста совпадают по SHA256. Исходные module-файлы не изменялись.
- Сам verifier: 6 unit-тестов успешно (совпадение, изменение, отсутствие файла,
  неверный digest, выход за корень, symlink). Повтор:
  `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tools -p 'test_*.py' -v`.
- Синтаксис: 8 Python-файлов и 3 JS/MJS-файла успешно.
- Overlay 17 файлов выполнен на **новой временной копии полного хоста**, не на
  исходниках и не на полном экспортированном репозитории.
- На overlay-хосте: Python **106 тестов (105 успешно, 1 PostgreSQL integration
  skipped)**; обе frontend suites **26 успешно**; seed safety **6 успешно**.
  Те же результаты получены непосредственно на полном экспортированном хосте.

Это не доказательство standalone-работоспособности: компонент не является
самостоятельным приложением. БД, контейнеры и настоящий browser smoke не
запускались; команды интеграции и ограничения описаны в `INTEGRATION.md`.

Все файлы до staging и staged Git blobs проверены offline на ключи, токены,
пароли, DSN, известные локальные секреты, частные IP и персональные пути;
дополнительно использован `detect-secrets 1.5.0 --no-verify`. Одна password-находка
в тесте — синтетическая mocked create-user фикстура. Все 58 entropy-находок в
manifest — вычисленные SHA256 и проверены по соответствующим файлам, не секреты.
Тесты не исключались целиком. Необработанных находок нет; отчёты без значений
хранятся вне репозитория. Эвристики не гарантируют отсутствие любого секрета;
перед публикацией необходим финальный просмотр владельцем.

После review оба gitignore дополнены `*.bak`, `*.old`, `*.orig`, `*~`;
`git check-ignore` подтверждает защиту составных имён `private.pem.bak`,
`private.key~` и вложенных backup-копий без создания реальных секретных файлов.
Манифест не изменялся: shared-файлы и 17 файлов overlay остались побайтно прежними.
106 тестов хоста включают 8 новых тестов его интерактивного admin bootstrap;
сам helper принадлежит полному хосту и не поставляется в компоненте.
Повторно проверено содержимое итогового commit на секреты. `git ls-files --stage`
подтвердил отсутствие symlinks/submodules; после amend остался один commit на main,
статус чистый, remote отсутствует.
