# Stage3 — импорт вопросов из JSON: ручная приёмка

Готово на частном **dev-стенде**, 2026-11-10: раздел `#/competencies?tab=responsible` (адрес стенда предоставляет владелец отдельно). Только первый этап Stage3 — импорт банка вопросов; следующие этапы ожидают отдельного согласования. После обновления вкладки несохранённые правки в ней пропадут.

## Как проверить

Войти в роли существующего ответственного КК демонстрационного отдела (прежние реквизиты, пароли в документе отсутствуют). Открыть **Компетенции → Ответственный за КК → Тестирование → Импорт вопросов из JSON**. Сохранить приведённый ниже пример в файл с расширением `.json` в UTF-8, при повторном использовании заменить все `external_id` на уникальные значения. Выбрать файл и нажать **«Загрузить JSON»**. Это демо-данные; не загружайте реальные материалы клиентов без разрешения.

```json
{
  "questions": [
    {
      "external_id": "manual-safe-001",
      "competency_code": "SAFE",
      "question": "Демо: какой вариант выбран для проверки?",
      "type": "single",
      "options": [
        {"id": "a", "text": "Вариант А", "is_correct": true},
        {"id": "b", "text": "Вариант Б", "is_correct": false}
      ]
    },
    {
      "external_id": "manual-wiki-002",
      "competency_code": "WIKI",
      "question": "Демо: исправьте тип вопроса перед одобрением",
      "type": "wrong_type",
      "options": [
        {"id": "a", "text": "Вариант А", "is_correct": true},
        {"id": "b", "text": "Вариант Б", "is_correct": false}
      ]
    },
    {
      "external_id": "manual-wiki-003",
      "competency_code": "WIKI",
      "question": "Демо: эту запись можно отклонить",
      "type": "single",
      "options": [
        {"id": "a", "text": "Вариант А", "is_correct": true},
        {"id": "b", "text": "Вариант Б", "is_correct": false}
      ]
    }
  ]
}
```

Формат: корневой массив из 1–200 объектов **или** объект `{ "questions": [...] }`; у каждой записи свой непустой `external_id` (до 128 символов), код компетенции **активной утверждённой карты своего отдела**, текст `question` (или `body`), `type` — `single`/`multiple`, 2–20 вариантов с уникальными `id`, текстом `text` (или `body`) и булевым `is_correct` (или `correct`). Для `single` ровно один правильный вариант, для `multiple` — хотя бы один. Не указывайте оба варианта названия одного поля одновременно. `explanation`, `source_page_id` и `source_revision_id` необязательны. Источник должен быть доступной статьёй своего отдела; версия, если задана, должна быть текущей. Если задана статья без версии, перед одобрением требуется явное подтверждение выбора текущей версии. Файл не более 512 КиБ, запрос не более 1 МиБ. JSON с повторяющимися ключами или невалидным UTF-8 отклоняется.

- [ ] После загрузки: **2 на проверке, 1 с ошибкой**, три отдельных записи с пояснениями; исходный JSON остаётся неизменным, в банк не поступил ни один вопрос.
- [ ] В записи `manual-wiki-002` выбрать тип **«Один ответ»** → **«Сохранить правки»**. Исходная и исправленная версии видны рядом; одобрение возможно только после сохранения и повторной валидации. Одобрить её и `manual-safe-001`; `manual-wiki-003` отклонить с причиной.
- [ ] Отчёт покажет **2 одобрено, 1 отклонено**, статус обработан. В банке ответственного появились ровно два новых одобренных вопроса. **«Варианты и ключ»** показывает правильный ответ, запись импорта и (при наличии) ссылку на статью-источник; ссылка на импорт открывает его карточку.
- [ ] Для ролей руководителя и сотрудника демонстрационного отдела импорты недоступны, ключи и приватные подробности банка не видны. Существующие опубликованные версии и назначения не поменялись.

Не используйте приведённые `external_id` повторно в **одном** файле: дубликаты помечаются ошибкой и исправляются отдельным сохранением. Повторный импорт файла создаёт новый импорт, поэтому сначала проверьте историю. При конфликте 409 обновите импорт и проверьте запись; не отправляйте решение повторно вслепую. Отмена одобрения/отклонения и редактирование уже рассмотренных записей не предусмотрены. Импорт не меняет вопросы опубликованных тестов и не создаёт новые версии тестов автоматически. Принципиально нет вызовов внешнего ИИ и обработки реальных материалов этим примером.
