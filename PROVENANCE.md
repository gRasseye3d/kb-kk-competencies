# Происхождение

Интегрированный модуль взят из текущих локальных рабочих файлов `kb/`, включая
новые файлы, а не из старой истории репозитория. Поставляемые Python/JS/CSS,
выбранные тесты, SQL 03–06, исходное ТЗ v4 и документы схемы скопированы побайтно.

- Исходная база знаний: https://github.com/Floressino/kb
  (базовый commit `5fce1e095c8e6b4e9fff1702c6533632a1a3beff`).
- Связанный проект компетенций: https://github.com/gRasseye3d/competency_module
  (базовый commit `fa15438b4d66ace065185ba2a21b890b179ce264`).
  Его самостоятельное приложение и авторизация не включены.
- Совместимый полный экспорт предназначен для https://github.com/gRasseye3d/kb-kk;
  наличие этого remote-репозитория не предполагается и его создание не выполнялось.

Это отдельный снимок без старой `.git`-истории, не форк с сохранёнными commits.
Лицензия не выдумана и не добавлена; владелец самостоятельно проверяет права на
публикацию и использование исходных материалов. Приватный компонент также
содержится в планируемом публичном полном проекте.
